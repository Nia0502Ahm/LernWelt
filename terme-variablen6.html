🧮 Terme und Variablen

📖 Das Thema erklärt

Eine Variable ist ein Buchstabe, der für eine Zahl steht. Ein Term ist ein Rechenausdruck mit Zahlen und Variablen. Zum Beispiel ist 3 + x ein Term. Wenn x = 5 ist, ergibt 3 + x = 8.

💡 Beispiele

3 + x → Term

x + 5 → Term

2 · x → Term

Wenn x = 4: 2 · x = 8
